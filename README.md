# Scroll Lock on Resize Chrome Extension

This repository holds the extension's source code.

With this extension you can select an element with right click and always have it in the middle of the screen when resizing and checking different viewports. Selected element will be highlighted with yellow lines. Just single click on any place of the page to turn it off. (SS1.png)

### Install from local files:

1. Download zip and uncompress.
2. Open Chrome -> Manage Extensions.
3. Enable `Developer mode`.
4. Click `Load Unpacked` and select the folder with the code.
